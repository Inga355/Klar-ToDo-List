# Working agreement

- Develop on descriptive `codex/` branches. Never implement on main.
- Small coherent commits; push each commit; one milestone PR targeting main.
- Never merge, force-push or delete unrelated work without explicit authorization.
- Review staged files before publishing. Exclude credentials and local user data.
- Keep German UI text, accessible contrast and keyboard navigation.
- Verify persistence, reminder dates, backup restore and cross-window consistency.
- Document unverified behavior honestly. Do not present browser tests as native Windows verification.
